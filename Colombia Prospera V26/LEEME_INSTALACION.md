# Iniciar Altium Financiero

Descomprime la carpeta completa.

En Windows, haz doble clic en **INICIAR_STREAMLIT.bat**. El iniciador busca Python, prepara las dependencias y abre el navegador. Conserva la ventana abierta mientras utilizas Altium.

En macOS o Linux, instala Python 3.11 o posterior y ejecuta `python3 preparar_altium.py` desde esta carpeta.

Necesitas Internet en la primera ejecución para instalar las dependencias. Después carga el Excel desde el panel. Si falla un paso, corrige el problema indicado y vuelve a ejecutar el iniciador.

Para detener la aplicación, presiona Ctrl+C en la ventana donde la iniciaste.

La alternativa Docker y los nombres de las hojas se explican en **README.md**.
