# Colombia Prospera V26

## Publicación en Streamlit Community Cloud

Sube el contenido de esta carpeta a la raíz del repositorio de GitHub. app.py y requirements.txt deben verse directamente al abrir el repositorio, sin otra carpeta intermedia.

Configura el archivo principal como app.py y selecciona Python 3.12 en Advanced settings antes de desplegar. Si la aplicación existente usa otra versión de Python, debes eliminar ese despliegue de Streamlit y crearlo nuevamente para cambiar la versión. Conserva el repositorio de GitHub.

La aplicación permite guardar una copia de la plantilla pública en Drive, subir un Excel o leer un enlace público de Google Sheets/Drive. No requiere credenciales ni claves de IA.

No subas datos financieros personales, entornos locales ni registros de ejecución.
